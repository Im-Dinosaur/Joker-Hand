# Joker Hand — 중급 AI 프로토타입

2026-09-15 대화에서 확정한 규칙의 첫 구현. 수치는 밸런스 검증 전 테스트값이다.

## 실행

Unity 6000.6.0f1에서 프로젝트를 열고 **Joker Hand → Open Prototype** 메뉴를 선택한 뒤 Play를 누른다. 전용 장면은 `Assets/Scenes/JokerHandPrototype.unity`이며 기존 SampleScene은 수정하지 않는다.

준비 화면에서 서로 다른 조커 3종을 고른다. 초기 선택은 신규 무료 지급 세트인 유지·활용형, 결단형, 페어형이다. 이 프로토타입에서는 6종 모두 선택 가능하며 실제 계정 지급이나 재화 저장은 하지 않는다. AI 후보 3종은 매치 시작 시 공개된다.

카드는 클릭/탭으로 선택하고 확정한다. 교체할 카드는 주황색, 현재 자신의 최선 족보에 쓰이는 카드는 초록색으로 표시한다. 창이 작으면 화면을 스크롤할 수 있다. 화면은 기능 확인용 IMGUI이며 최종 제품 디자인이 아니다.

## 한 판의 흐름

1. 공유된 52장 덱에서 각자 개인 카드 2장을 받고 공용 카드 3장을 공개한다.
2. 15초 동안 개인 카드 0~2장을 교체 대상으로 선택한다. 확정 전에는 변경할 수 있으며 확정 후에는 잠긴다. 시간 초과 시 현재 선택대로 확정한다.
3. 두 플레이어가 확정하면 동시에 교체를 처리하고 버린 카드를 공개한다. 버린 카드는 이번 판에 재사용하지 않는다.
4. 네 번째 공용 카드를 공개한다. 후보 3종에서 조커 1종을 선택하는 시간은 30초다.
5. 선택된 조커가 있으면 시간 초과 시 그대로 확정한다. 아무 선택도 없으면 현재 카드 6장만으로 점수가 가장 높은 후보를 고른다. 동점이면 후보 목록에서 먼저 나온 조커를 고른다. 예측 입력은 자동 생성하지 않는다.
6. 양쪽 선택을 잠근 뒤 조커를 동시에 공개하고, 마지막 공용 카드, 양쪽 개인 카드, 점수 계산, 승패 순서로 약 5초 동안 보여준다. 예측 내용은 조커 점수 계산 단계에서 공개한다.

각 결정 단계에서 빨간색 NOT READY / 초록색 READY를 표시한다. 둘 다 일찍 확정하면 바로 진행한다. 기권은 즉시 상대 승리이며 보상을 지급하지 않는다. 네트워크 연결·PVP·재화 지급·강화·랭킹·모바일 검증은 아직 구현하지 않았다.

## 점수 규칙

| 족보 | 기본 점수 | 숫자 보정 범위 |
|---|---:|---:|
| 하이카드 | 1,000 | 0~1,276 |
| 원페어 | 3,000 | 0~2,859 |
| 투페어 | 7,000 | 0~857 |
| 트리플 | 13,000 | 0~857 |
| 스트레이트 | 21,000 | 0~9 |
| 플러시 | 33,000 | 0~1,276 |
| 풀하우스 | 50,000 | 0~155 |
| 포카드 | 75,000 | 0~155 |
| 스트레이트 플러시 | 110,000 | 0~8 |
| 로열 플러시 | 160,000 | 0 |

각 족보의 서로 다른 숫자·키커 조합을 표준 포커 순서로 정렬한 순번이 숫자 보정이다. A2345는 가장 낮은 스트레이트이고 무늬 간 우위나 무늬 점수는 없다. 조커 적용 전에는 상위 족보가 반드시 더 높은 점수다.

개인 카드 2장과 공용 카드 5장 중 가장 강한 5장을 선택한다. 개인 카드를 0~2장 사용할 수 있다. 동등한 포커 강도의 선택지가 여러 개라면 선택한 조커 점수를 최대화하는 5장을 사용한다. 조커에 유리하다는 이유로 더 약한 포커 족보를 선택하지 않는다.

| 조커 | 기본 조건과 효과 | 추가 조건과 최종 효과 |
|---|---|---|
| 유지·활용형 | 개인 카드 두 장 모두 최종 5장에 사용: +3,000 | 교체도 하지 않았다면 총 +8,000 |
| 예측형 | 항상 +2,000 | 마지막 카드 숫자 적중: 총 +12,000 / 숫자·무늬 적중: 총 +112,000 |
| 간파형 | 자신이 상대보다 적게 교체: +4,000 | 최종 투페어 이상이면 총 +9,000 |
| 결단형 | J·Q·K·A 중 한 장 이상 버림: +2,000 | 새로 받은 카드 한 장 이상을 최종 5장에 사용하면 총 +7,000 |
| 플러시 특화형 | 최종 플러시·스트레이트 플러시·로열 플러시: ×1.5 | 네 번째 카드까지 플러시가 없었으나 다섯 번째 카드로 완성했다면 ×2.0 |
| 페어형 | 교체 후 개인 카드 두 장이 페어: ×1.3 | 그 두 장을 최종 5장에 사용해 투페어·트리플·풀하우스·포카드를 만들면 ×1.8 |

배율은 `족보 기본 점수 + 숫자 보정`에 한 번 적용한다. 추가 조건은 배율을 높이며 기본 배율과 곱하지 않는다. 모든 실제 계산을 마친 뒤 한 번 소수점을 버린다. 표시하는 정수 점수가 같으면 무승부다. 중간 연출 점수는 최종 계산의 입력으로 재사용하지 않는다.

예측형의 무늬만 적중하거나 예측 입력이 없으면 기본 보너스만 받는다. 알고 있는 개인 카드·공용 카드·공개된 버린 카드는 예측으로 지정할 수 없다. 모든 조커는 자신의 점수만 높인다.

선택 화면의 점수는 현재 카드 기준이며 미래의 추가 보너스를 미리 지급하지 않는다. 최종 5번째 카드가 나오면 족보와 조건을 다시 판정한다.

## 중급 AI의 판단 방식과 한계

`Observation`은 자신의 개인 카드, 공개 공용 카드, 공개된 양쪽 버린 카드, 자신의 교체 이력, 양쪽 후보만 담은 복사본이다. AI에는 Match 객체, 실제 덱 순서, 상대 개인 카드, 상대의 미확정 선택·예측, 덱 생성 난수를 전달하지 않는다.

- 교체: 0장/첫 번째/두 번째/두 장의 네 선택마다 48개의 교체·네 번째 카드 표본을 계산한다. 각 표본에서는 마지막 카드 12개를 고려해 선택할 조커의 평균 점수를 비교한다. 마지막 카드를 본 뒤 최선 조커를 고르는 식의 미래 정보 사용은 하지 않는다.
- 상대 교체는 동시에 이루어지므로 아직 모른다. 현재 중급 정책은 상대의 0/1/2장 교체를 균등하게 가정한다. 상대 패턴을 학습하거나 후보 구성에 따른 상대 행동을 추론하는 정책은 아직 없다.
- 조커 선택: 네 번째 카드가 공개된 시점에서 알려진 카드를 제외한 모든 마지막 카드 후보를 열거하고 평균 최종 점수를 최대화한다. 실제 숨은 상대 카드도 AI 관점에서는 가능한 카드에 포함된다. 이는 정보를 모르는 상태의 추정이며 실제 덱을 다시 채우는 동작이 아니다.
- 예측: 남아 있을 가능성이 있는 카드 수가 가장 많은 숫자를 고르고 그 숫자의 가능한 무늬 하나를 확정한 후 결과를 비교한다. 실제 마지막 카드를 보고 예측을 바꾸지 않는다.
- 사용자 시간 초과 자동 선택과 AI의 선택은 다르다. 자동 선택은 현재 점수만 비교하지만 중급 AI는 마지막 카드의 가능성까지 고려한다.
- 이 정책은 자신의 평균 점수를 최적화한다. 상대 최종 점수에 대한 승률 최적화나 고급 상대 전략 추론은 하지 않는다. 48×12 표본 수와 상대 교체 가정은 구현용 초기값이며 추후 플레이 테스트로 조정한다.

## 검증

화면은 `Document/References/Match_Layout_Sketch.png`의 배치를 따른다. 내 카드와 조커 후보 사이의 버튼은 교체 단계에 `교체 확정`, 조커 단계에 `조커 확정`이며 본인 확정 후 숨긴다. 다음 선택 단계에는 다시 표시하고 결과에서는 숨긴다. 조커 후보에는 회색 반투명 덮개와 카드 위 현재 적용 점수를 표시한다. 후보 선택 시 덮개를 걷고 해당 후보로 최고 점수를 만드는 5장에 초록색 테두리를 표시한다. 최상위 포커 족보가 같은 복수 조합에서도 선택 조커의 점수를 기준으로 강조 대상을 정한다.

화면 명세 개정 1 검증: PlayMode 검사에 확정 버튼의 단계별 문구와 본인 확정·결과 시 숨김 검사를 추가했다. Unity 에디터에서 1920×1080 Game 화면의 배치와 조커 덮개·점수·선택 전환을 직접 확인했다. 모바일 실기기 사용성은 후속 검증 대상이다.

프로젝트 루트에서 PowerShell로 `./Tests/RunCoreChecks.ps1`을 실행한다. 설치된 .NET SDK의 C# 컴파일러를 직접 사용하므로 추가 패키지나 NuGet 연결은 필요하지 않다. 결과물은 무시되는 `Temp/CoreChecks`에 생성된다.

일반 .NET 환경에서는 `dotnet run --project Tests/CoreHarness/CoreHarness.csproj --configuration Release`로도 실행할 수 있다.

자동 검사는 전체 2,598,960개 5장 물리 카드 조합의 족보별 개수, 7,462개 숫자 조합, 족보 경계와 키커, 조커 6종, 동급 최선 5장 선택, 버림 계산, 단계별 정보 공개, 시간 초과, 기권, 100판의 카드 중복·버린 카드 재사용 방지, AI의 미래 보상 고려 및 비공개 선택에 대한 독립성을 확인한다.

수치 밸런스, 모바일 조작감, 최종 그래픽 품질은 이 자동 검사의 검증 대상이 아니다.
