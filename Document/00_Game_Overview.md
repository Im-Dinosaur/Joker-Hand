# Joker Hand 게임 개요와 핵심 루프

기획 기준 버전 0.2

Joker Hand는 개인 카드와 공용 카드로 포커 족보를 만들고, 준비한 조커 후보 중 하나를 선택해 최종 점수로 경쟁하는 2D 1대1 카드게임이다. 이 문서는 기획·개발·테스트 담당자가 게임의 목표와 범위를 공유하기 위한 상위 기획서다. 대전 절차, 계산 규칙, 조커 조건은 문서 01~04의 상세 명세를 따른다.

## 1 문서 기준과 상태

| 상태 | 의미 | 적용 원칙 |
|---|---|---|
| 확정 규칙 | 사용자와 합의한 동작과 제약 | 임의로 변경하지 않고 후속 결정 시 갱신 |
| 테스트 기준 | 첫 프로토타입에 사용하기로 승인한 수치 | 적용은 확정됐으나 최종 밸런스는 미확정 |
| 방향 확정 | 목표 또는 정책이 합의된 상태 | 세부 수치와 예외는 후속 설계 필요 |
| 구현 선택 | 프로토타입 구현을 위해 채택한 방법 | 기획상 영구 규칙으로 취급하지 않음 |
| 미결정 | 아직 합의하지 않은 항목 | 구현 편의를 이유로 확정 사항에 편입하지 않음 |

기획 상태와 구현 상태는 별개다. 예를 들어 실시간 PvP와 성장 반영 정책은 방향이 정해졌지만 아직 구현되지 않았다. 기존 문서와 충돌하면 후속 사용자 결정이 우선하며, 현재 코드의 동작만으로 새 기획이 확정되지는 않는다.

문서 작성·정리: 개발 보조 AI. 기획 의사결정: 프로젝트 사용자. 본 버전은 합의된 규칙과 첫 테스트 수치를 관리하는 기준선이다.

## 2 제품 정의

| 항목 | 현재 기준 | 상태 |
|---|---|---|
| 작업명 | Joker Hand | 프로젝트 명칭 |
| 장르와 인원 | 2D 1대1 점수 경쟁 카드게임 | 확정 규칙 |
| 플레이 환경 | PC와 모바일 가로 화면 | 방향 확정 |
| 개발 순서 | PC 핵심 루프를 먼저 완성하고 모바일 조작 검증 | 확정 규칙 |
| 기본 카드 | 두 플레이어가 공유하는 표준 트럼프 52장 | 확정 규칙 |
| 족보 구성 | 개인 카드 2장과 공용 카드 5장 중 최선의 5장 | 확정 규칙 |
| 조커 구성 | 서로 다른 후보 3종을 준비하고 대전 중 1종 활성화 | 확정 규칙 |
| 승리 조건 | 조커 적용 후 정수 최종 점수가 더 높음 | 확정 규칙 |
| 대전 모드 | AI 대전을 먼저 구현하고 실시간 PvP로 확장 | 방향 확정 |
| 플레이 길이 | 짧은 반복 대전 지향, 60초 미만 종료 허용 | 확정 규칙 |

최초의 1~3분 목표는 최소 60초를 채워야 한다는 요구가 아니다. 현재 결정 제한시간은 교체 15초, 조커 선택 30초이고 결과 공개 연출은 약 5초다. 둘 다 일찍 확정하면 즉시 진행한다. 매칭·준비·결과 화면 체류까지 포함한 실제 세션 길이는 별도 측정한다.

## 3 플레이 경험 목표

G-01 짧은 판 안에서 카드를 유지할지 교체할지 결정하고 결과를 확인한다. 친구와 가볍게 반복할 수 있는 경험을 지향한다.

G-02 상대의 조커 후보, 교체한 카드와 장수를 보고 전략을 추론한다. 공개 정보는 판단에 사용하되 상대의 비공개 카드나 미확정 선택을 먼저 볼 수 없다.

G-03 포커의 족보·숫자 우열을 조커 적용 전 점수에 보존한다. 조커 적용 후에는 낮은 족보도 최종 점수로 역전할 수 있다.

G-04 큰 조건 보너스와 배율로 강한 성취감을 만든다. 큰 숫자 자체가 재미나 재플레이를 보장한다고 가정하지 않고, 이해 가능성·선택의 영향·역전 경험을 테스트한다.

G-05 수집과 강화의 성취를 유지하면서 신규 플레이어가 과도한 성장 격차에 노출되지 않게 한다. 동시에 접속한 사람이 적어도 AI 대전으로 핵심 경험을 제공한다.

## 4 핵심 루프

### 4 1 한 판의 플레이 루프

1. 서로 다른 조커 후보 3종을 구성한다.
2. 상대와 대전을 시작하고 양쪽 후보의 효과 정보를 확인한다.
3. 개인 카드 2장과 공용 카드 3장을 확인한다.
4. 개인 카드 0~2장을 교체 대상으로 선택하고 확정한다.
5. 양쪽의 버린 카드 공개와 교체 후 네 번째 공용 카드를 확인한다.
6. 현재 족보, 교체 이력, 상대 정보와 마지막 카드 가능성을 고려해 조커 1종을 선택한다.
7. 양쪽 조커를 동시에 공개한 뒤 마지막 공용 카드와 개인 패를 공개한다.
8. 최선의 족보와 조커 효과를 계산하고 승패를 확인한다.

### 4 2 반복 성장 루프

대전 완료 → 결과에 따른 재화 획득 → 조커 획득 및 중복 조커 강화 → 후보 조합 재구성 → 다음 대전.

이 성장 루프는 방향이 확정됐으며 현재 프로토타입에는 재화·계정·획득·강화 기능이 없다. 신규 플레이어에게는 유지·활용형, 결단형, 페어형을 무료로 지급한다는 정책이 정해졌다. 정확한 획득 확률, 비용과 강화 표는 미결정이다.

### 4 3 핵심 선택과 보상

| 선택 | 판단 정보 | 선택이 바꾸는 결과 |
|---|---|---|
| 후보 3종 구성 | 조커 조건과 자신이 선호하는 전략 | 판 안에서 선택할 수 있는 점수 전략 |
| 카드 유지 또는 교체 | 개인 카드 2장, 공용 카드 3장, 상대 후보 | 족보 가능성, 교체 이력 조건, 상대에게 공개할 정보 |
| 조커 활성화 | 공용 카드 4장, 교체 후 패, 공개된 버린 카드 | 안정적인 현재 보상과 마지막 카드에 대한 기대 보상 |
| 마지막 카드 예측 | 예측형을 선택했을 때 현재 알려진 카드 | 숫자 적중과 완전 적중의 큰 추가 점수 |

현재 규칙에서 상대의 활성 조커는 두 사람의 선택이 잠긴 후 공개된다. 공개된 활성 조커를 본 뒤 다시 선택하는 단계는 없다. 대응 전략은 상대의 사전 후보와 공개된 교체 이력을 바탕으로 구성한다.

## 5 개발 범위

첫 프로토타입은 조커 6종, 후보 구성, 카드 지급과 교체, 조커 선택, 족보·점수, 시간 초과와 결과 공개, 중급 AI 대전을 포함한다. 핵심 루프의 재미를 확인한 뒤 수집·강화·재화·PvP·랭킹 등을 추가한다.

실시간 PvP는 최종 경험의 방향이다. 친구 대전 방식, 낮은 동시접속자 상황의 자동 AI 전환, 비동기 대전과 고스트 대전은 세부 확정이 필요하다. 서버 기술이나 상용 서비스를 이 문서에서 새로 선택하지 않는다.

## 6 용어

| 용어 | 정의 |
|---|---|
| 개인 카드 | 해당 플레이어에게만 보이는 일반 카드 2장 |
| 공용 카드 | 두 플레이어가 함께 사용하는 공개 카드, 최종 5장 |
| 교체 또는 리롤 | 개인 카드 0~2장을 한 번 선택해 새 카드로 바꾸는 행동 |
| 후보 조커 | 대전 전에 준비한 서로 다른 조커 3종 |
| 활성 조커 | 네 번째 공용 카드 후 선택해 이번 판에 적용하는 조커 1종 |
| 최선의 5장 | 현재 카드에서 포커 강도가 가장 높은 5장 |
| 숫자 보정 | 같은 족보 안의 숫자·키커 우열을 보존하는 정수 순번 |
| 현재 기준 점수 | 아직 마지막 카드가 없는 현재 카드만으로 계산한 참고 점수 |

## 7 문서 구성과 참조 기준

00 게임 개요와 핵심 루프: 제품 목표, 선택 구조, 범위.

01 대전 시스템과 화면 명세: 상태 전이, 정보 공개, 입력, 자동 처리와 결과 연출.

02 족보와 점수 시스템: 최선 패 판정, 숫자 비교, 점수표, 계산 순서와 동점.

03 조커 상세 기획: 공통 규약, 조커 6종의 조건·효과·예외·검수 항목.

04 성장과 AI 및 개발 관리: 획득·강화·매칭·보상 정책, AI, 구현 상태, 변경 이력과 미결정 사항.

출처는 사용자가 제공한 Requirements v0.1, Game Design v0.1, Design Review v0.1, 이후의 사용자 결정, 프로젝트 코드 및 프로토타입 안내서다. 이전 문서는 역사적 기준이며, 개인 카드 5장·무늬 배수·무늬 동점 우위 등 후속 결정으로 대체된 규칙은 현재 시스템에 적용하지 않는다.
