# Joker Hand 족보와 점수 시스템

기획 기준 버전 0.2

이 문서는 포커 강도를 판단하는 단계와 조커로 점수를 높이는 단계를 구분한다. 조커 적용 전에는 표준 포커의 족보·숫자 우열을 보장하고, 조커 적용 후에는 최종 정수 점수로만 승패를 결정한다. 아래 점수표와 배율은 승인된 첫 테스트값이며 최종 밸런스 검증은 남아 있다.

## 1 최선의 족보 선택

S-01 최종 보유 카드 7장인 개인 카드 2장과 공용 카드 5장에서 가장 강한 5장을 고른다. 개인 카드는 0장, 1장, 2장 모두 사용 가능하다. 개인 카드 두 장을 의무적으로 포함하지 않는다.

S-02 서로 다른 5장 구성이 같은 족보와 숫자·키커 강도를 가지면, 활성 조커 적용 후 점수가 가장 높은 구성을 자동 선택한다. 조커 점수를 높이기 위해 더 약한 포커 강도의 5장을 고르지는 않는다.

예: 공용 카드 A스페이드, K하트, Q다이아몬드, J클로버, 10스페이드와 개인 카드 A하트, K클로버가 있다. 공용 카드만으로도 A 최고 스트레이트이며 개인 A·K를 사용하는 구성도 같은 강도다. 유지·활용형을 사용한다면 개인 A·K가 들어간 동급 스트레이트를 선택해 조건을 인정한다.

S-03 교체 시점에는 카드 5장, 조커 선택 시점에는 카드 6장으로 현재 최선의 5장을 계산한다. 마지막 공용 카드가 나오면 카드 7장으로 다시 평가한다.

## 2 족보 정의와 점수표

| 순위 | 족보와 정의 | 기본 점수 | 숫자 보정 범위 |
|---|---|---:|---:|
| 1 | 하이카드 — 다른 족보가 없는 5장 | 1,000 | 0~1,276 |
| 2 | 원페어 — 같은 숫자 2장 | 3,000 | 0~2,859 |
| 3 | 투페어 — 서로 다른 숫자의 페어 2개 | 7,000 | 0~857 |
| 4 | 트리플 — 같은 숫자 3장 | 13,000 | 0~857 |
| 5 | 스트레이트 — 연속 숫자 5장 | 21,000 | 0~9 |
| 6 | 플러시 — 같은 무늬 5장 | 33,000 | 0~1,276 |
| 7 | 풀하우스 — 트리플과 별도 숫자의 페어 | 50,000 | 0~155 |
| 8 | 포카드 — 같은 숫자 4장 | 75,000 | 0~155 |
| 9 | 스트레이트 플러시 — 같은 무늬의 연속 5장, 로열 제외 | 110,000 | 0~8 |
| 10 | 로열 플러시 — 같은 무늬 10 J Q K A | 160,000 | 0 |

상위 족보일수록 기본 점수 사이의 간격이 커진다. 이 수치는 해당 족보의 실제 발생 확률을 정확히 역수로 변환한 표가 아니다. 공용 카드와 교체가 있는 게임의 발생 빈도·체감 보상은 플레이 테스트에서 별도로 확인한다.

## 3 숫자와 키커 비교

S-04 숫자 우위는 A, K, Q, J, 10부터 2 순서다. 스트레이트에서는 A2345의 최고 숫자를 5로 취급하고, 10JQKA의 최고 숫자는 A다. QKA23 같은 순환 스트레이트는 허용하지 않는다.

| 족보 | 같은 족보 안에서 비교하는 순서 |
|---|---|
| 하이카드·플러시 | 가장 높은 숫자부터 다섯 장을 차례로 비교 |
| 원페어 | 페어 숫자 → 높은 키커 → 다음 키커 → 마지막 키커 |
| 투페어 | 높은 페어 → 낮은 페어 → 키커 |
| 트리플 | 트리플 숫자 → 높은 키커 → 낮은 키커 |
| 스트레이트·스트레이트 플러시 | 연속 조합의 최고 숫자, A2345는 5 |
| 풀하우스 | 트리플 숫자 → 페어 숫자 |
| 포카드 | 포카드 숫자 → 키커 |
| 로열 플러시 | 숫자 강도 동일, 무늬로 순위를 나누지 않음 |

키커는 같은 주 구성의 우열을 판정할 때 사용하는 나머지 카드다. 예를 들어 같은 K 원페어라면 높은 키커부터 비교한다. K 원페어는 어떤 키커를 가진 Q 원페어보다도 높다.

S-05 무늬 배수와 무늬 우선순위는 없다. 무늬는 플러시 판정이나 예측 등 조건에만 사용한다. 점수가 같을 때 스페이드 우위 같은 보조 판정을 적용하지 않는다.

## 4 숫자 보정 방식

S-06 각 족보에서 가능한 서로 다른 숫자·키커 조합을 표준 포커 순서로 정렬한다. 가장 약한 조합에 0, 다음 조합에 1을 부여하는 정수 순번을 숫자 보정으로 사용한다. 무늬만 다른 동급 조합의 순번은 같다.

이 방식은 카드 숫자를 단순 합산하거나 기존 제안의 0~199로 압축하는 방식이 아니다. 원페어에만 2,860개의 서로 다른 강도가 있으므로 모든 강도를 정수로 구분할 공간이 필요하다. 보정값의 크기는 족보별 가능한 강도 개수에 따라 달라진다.

S-07 족보 기본 점수와 숫자 보정을 합친 결과에서도 족보 순위가 뒤집히지 않아야 한다. 가장 강한 하이카드는 2,276점으로 가장 약한 원페어 3,000점보다 낮다. 가장 강한 원페어는 5,859점으로 가장 약한 투페어 7,000점보다 낮다. 같은 조건을 모든 족보 경계에 적용한다.

## 5 최종 계산 순서

1. 현재 또는 최종 카드 집합에서 표준 포커 강도가 가장 높은 5장 구성을 구한다.
2. 같은 강도의 구성이 여럿이면 활성 조커 조건까지 평가해 최종 점수가 가장 높은 구성을 선택한다.
3. 족보 기본 점수와 숫자 보정을 더한다.
4. 활성 조커의 조건을 판정하고 고정 가산점 또는 최종 배율을 적용한다.
5. 모든 실제 계산이 끝난 후 소수점 이하를 한 번 버린다.
6. 양쪽 정수 최종 점수를 비교한다. 같으면 무승부다.

현재 점수형 조커의 최종 점수는 ‘족보 기본 점수 + 숫자 보정 + 성립한 가산점의 합’이다. 배율형은 ‘족보 기본 점수와 숫자 보정의 합에 해당 조건의 최종 배율을 한 번 적용한 값’에서 소수점을 버린다.

현재 6종에는 하나의 조커가 가산점과 배율을 동시에 주는 혼합형이 없다. 향후 혼합형을 추가할 경우 더하기와 곱하기의 우선순위를 별도 결정해야 한다. 프로토타입의 내부 공통 계산식이 있다는 이유로 미래 혼합형의 기획 순서를 확정하지 않는다.

## 6 계산 예시

### 6 1 점수형으로 족보 역전

숫자 보정을 제외한 설명용 비교에서 투페어 7,000점에 유지·활용형의 두 조건을 모두 충족하면 8,000점이 더해져 15,000점이다. 조커 효과가 없는 트리플 13,000점보다 높을 수 있다. 실제 대전에서는 각각의 숫자 보정과 상대 조커 효과까지 계산한다.

### 6 2 배율 상향

숫자 보정을 제외한 플러시 33,000점은 플러시 특화형 기본 조건으로 49,500점이 된다. 마지막 카드로 처음 플러시를 완성했다면 최종 배율 2.0을 한 번 적용해 66,000점이다. 1.5와 2.0을 연속 적용해 99,000점으로 계산하지 않는다.

### 6 3 소수점 처리

산술 설명용 입력값 7,001점에 1.3배를 적용하면 9,101.3점이다. 최종 표시와 승패 판정에는 9,101점을 사용한다. 중간 연출에서 보여준 정수 점수를 다음 계산의 입력으로 재사용하지 않는다.

### 6 4 예측 보너스 누적

예측형은 기본 2,000점, 숫자 적중 추가 10,000점, 숫자·무늬 모두 적중 추가 100,000점이다. 완전 적중하면 총 112,000점이 추가된다. 정확히 맞혀도 상대의 최종 점수가 더 높다면 승리하지 못한다.

## 7 현재 기준 점수와 확정 점수

S-08 조커 선택 화면에서는 개인 카드 2장과 공용 카드 4장으로 각 후보의 현재 점수를 표시한다. 아직 발생하지 않은 보너스를 미리 더하지 않는다. 예측형은 기본 보너스만 반영하고 플러시 특화형의 마지막 카드 완성 보너스는 미확정으로 표시한다.

현재 성립한 최선의 5장이나 조커 조건도 마지막 카드 후 달라질 수 있다. 개인 카드 사용 조건이 사라지거나 더 높은 족보로 교체될 수 있으므로 현재 점수를 최종 보장 점수로 안내하지 않는다.

## 8 검수 기준과 한계

| ID | 검수 항목 | 기대 결과 |
|---|---|---|
| ST-01 | 모든 족보의 기본·보정 경계 | 조커 전 하위 족보가 상위 족보를 넘지 않음 |
| ST-02 | 원페어·투페어·풀하우스·포카드의 비교 | 주 구성 숫자를 키커보다 먼저 비교 |
| ST-03 | A2345, 10JQKA, QKA23 | 앞 두 조합만 스트레이트 허용 |
| ST-04 | 무늬만 다른 동일 숫자 조합 | 같은 족보 점수 |
| ST-05 | 같은 강도지만 개인 카드 사용 여부가 다른 5장 | 활성 조커 점수를 최대화하는 구성 선택 |
| ST-06 | 개인 페어보다 공용 로열 플러시가 강함 | 로열을 버리고 페어 조건을 우선하지 않음 |
| ST-07 | 소수점이 생기는 배율 | 최종 한 번 버림, 표시 점수로 판정 |
| ST-08 | 서로 다른 족보라도 최종 정수 동점 | 무승부 |

현재 자동 검사에는 2,598,960개의 물리적 5장 조합에 대한 족보별 분류 개수 확인과 7,462개 숫자 강도 조합, 경계·예외 검사가 포함된다. 이는 7장 게임의 모든 진행 경우와 밸런스를 전수 검증했다는 뜻은 아니다. 조커 선택률·승률·역전 빈도와 점수 설명 이해도는 후속 플레이 테스트 대상이다.
