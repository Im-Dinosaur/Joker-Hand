# Joker Hand 대전 시스템과 화면 명세

기획 기준 버전 0.2

이 문서는 한 판의 입력, 상태 전이, 정보 공개 및 예외 처리를 정의한다. 개인 카드 교체와 조커 선택은 각각 동시 선택 단계이며, 먼저 확정한 플레이어에게 추가 정보나 재선택 기회를 주지 않는다. 점수 산출은 문서 02, 조커별 조건은 문서 03을 따른다.

## 1 카드와 대전 데이터

M-01 일반 카드는 2~10, J, Q, K, A의 13개 숫자와 클로버·다이아몬드·하트·스페이드의 4개 무늬로 구성된 52장이다. 두 플레이어는 하나의 덱을 공유하며 같은 물리 카드를 중복 지급하지 않는다.

M-02 조커는 일반 카드와 분리된 효과 카드다. 일반 덱에 섞거나 숫자·무늬를 대체하는 와일드카드로 사용하지 않는다. 매치마다 후보 3종 중 활성 조커 1종만 적용한다.

M-03 교체로 버린 카드는 그 판의 버린 카드 존에 남는다. 개인 카드 재지급이나 공용 카드 공개에 재사용하지 않는다. 플레이어는 상대의 비공개 개인 카드를 모르므로 공개된 버린 카드만 보고 실제 덱의 남은 구성을 완전히 알 수는 없다.

M-04 개념상 필요한 판 데이터는 개인 카드, 순서가 있는 공용 카드, 후보·활성 조커, 교체 장수·버린 카드·새로 받은 카드, 확정 상태, 예측 값, 타이머, 최종 패와 점수다. 구체적인 네트워크 전송 형식은 미결정이다.

## 2 상태 전이

| 단계 | 진입 시 공개 또는 처리 | 허용 입력 | 종료 조건 |
|---|---|---|---|
| 준비 | 자신의 보유 조커와 후보 구성 | 서로 다른 후보 3종 선택 | 구성 완료 후 대전 시작 |
| 시작 | 양쪽 후보와 효과 정보 공개, 개인 카드 2장 지급, 공용 카드 3장 공개 | 카드와 후보 확인 | 교체 단계 진입 |
| 교체 선택 | 자신의 패와 공용 카드 확인 | 교체 대상 0~2장 선택·해제 및 확정 | 둘 다 확정 또는 15초 종료 |
| 교체 처리 | 양쪽 버린 카드 동시 공개, 새 카드 재지급 | 추가 교체 불가 | 네 번째 공용 카드 공개 |
| 조커 선택 | 공용 카드 4장, 교체 후 패와 버린 카드 확인 | 후보 1종 선택, 필요한 예측 입력, 확정 | 둘 다 확정 또는 30초 종료 |
| 조커 공개 | 양쪽 활성 조커 동시 공개 | 조커 재선택 불가 | 마지막 공용 카드 공개 |
| 쇼다운 | 다섯 번째 공용 카드 공개 후 양쪽 개인 카드 동시 공개 | 점수 과정 확인 | 계산과 결과 연출 종료 |
| 결과 | 정수 점수와 승리·패배·무승부 표시 | 다음 플레이 준비 | 결과 화면 종료 |

교체 15초는 확정 규칙이다. 조커 선택 30초와 결과 연출 약 5초는 승인된 테스트 기준이며 조정 가능하다. 준비·매칭 시간과 결과 화면 체류 제한은 확정하지 않았다.

## 3 교체 입력과 자동 처리

M-05 한 판에 교체 기회는 한 번이다. 0장 유지, 첫 카드만 교체, 두 번째 카드만 교체, 두 장 모두 교체가 가능하다. 0장 유지로 확정해도 이후 추가 교체 기회는 없다.

M-06 확정 전에는 선택과 해제가 가능하다. 확정 버튼을 누르면 선택이 잠기고 상대가 끝날 때까지 대기한다. 상대가 먼저 확정했더라도 자신의 15초가 끝나기 전에는 선택을 계속할 수 있다.

M-07 시간이 끝났는데 확정하지 않았다면 현재 선택한 카드를 그대로 교체한다. 선택하지 않은 카드는 유지한다. 아무 카드도 선택하지 않았다면 두 장 모두 유지한다.

M-08 교체 장수와 버린 카드의 정체는 양쪽의 선택이 모두 잠긴 뒤 동시에 공개한다. 선택 중인 카드, 먼저 확정한 플레이어의 교체 장수, 새로 받은 카드는 선공개하지 않는다. 새 개인 카드는 최종 쇼다운까지 상대에게 숨긴다.

## 4 조커 입력과 자동 처리

M-09 상대의 후보 3종은 시작 시 공개한다. 각 후보의 이름, 조건, 기본·추가 효과, 강화 수준과 실제 적용 수치를 볼 수 있어야 한다. 현재 프로토타입에는 강화가 없으므로 기본 테스트 수치만 표시한다.

M-10 네 번째 공용 카드 공개 후 후보 중 1종을 선택한다. 확정 전에는 후보를 바꿀 수 있고 확정 후에는 잠긴다. 먼저 확정한 조커는 상대에게 보여주지 않는다.

M-11 시간이 끝나면 선택해 둔 조커를 자동 확정한다. 아무 조커도 선택하지 않았다면 공용 카드 4장과 개인 카드 2장으로 현재 점수를 계산하여 가장 높은 후보를 선택한다. 동점이면 후보 목록에서 먼저 있는 조커를 선택한다. 아직 나오지 않은 카드의 기대 보너스를 자동 선택에 합산하지 않는다.

M-12 예측형의 숫자·무늬 입력은 조커 확정과 함께 잠긴다. 아무 예측을 지정하지 않았다면 기본 보너스만 받는다. 시간 초과로 예측형이 선택됐다는 이유로 예측 값을 자동 생성하지 않는다. AI가 판단 중 직접 예측을 입력하는 행위는 이 자동 확정 규칙과 별개다.

M-13 양쪽 활성 조커는 동시에 공개한다. 예측형의 예측 숫자·무늬는 그때 공개하지 않고 최종 점수 계산 단계까지 숨긴다. 활성 조커 공개 이후에는 새로운 선택 단계가 없다.

## 5 정보 공개 표

| 정보 | 본인 | 상대에게 공개되는 시점 |
|---|---|---|
| 후보 조커 3종과 효과 | 준비·대전 중 확인 | 대전 시작 |
| 최초 및 교체 후 개인 카드 | 지급 직후 확인 | 마지막 공용 카드 후 쇼다운 |
| 공용 카드 | 모두에게 동일 | 3장 → 네 번째 → 다섯 번째 |
| 현재 선택한 교체 대상 | 확정 전후 본인 확인 | 선택 중에는 비공개 |
| 교체 장수와 버린 카드 | 본인 이력 확인 | 양쪽 교체 확정 후 동시에 |
| 활성 조커 선택 | 본인 선택 확인 | 양쪽 조커 확정 후 동시에 |
| 예측 숫자와 무늬 | 본인 입력 확인 | 최종 조커 점수 계산 |
| READY 여부 | 각 단계마다 확인 | 확정 여부만 즉시 공개 |
| 실제 덱 순서와 다음 카드 | 플레이어에게 비공개 | 다음 카드가 실제로 공개될 때만 |

공정성 규칙은 인간과 AI에 동일하게 적용한다. 공개 전 상대 선택이나 실제 다음 카드에 접근해 의사결정을 내리면 안 된다.

## 6 화면과 조작 명세

### 6 1 준비 화면

UI-01 후보 구성은 PC 클릭과 모바일 탭으로 진행한다. 드래그를 필수 입력으로 요구하지 않는다. 같은 종류의 조커를 중복해서 후보에 넣을 수 없으며 세 슬롯을 채워야 대전을 시작할 수 있다.

UI-02 신규 무료 지급 세트는 유지·활용형, 결단형, 페어형이다. 테스트 준비 화면에서는 검증을 위해 조커 6종 모두 선택할 수 있다. 두 정책을 실제 지급 구현과 혼동하지 않는다.

### 6 2 대전 화면

UI-03 중앙에는 공용 카드, 본인 영역에는 개인 카드와 조커 후보, 상대 영역에는 공개된 후보와 확정 상태를 배치한다. 공개 이후에는 버린 카드 존에서 양쪽 교체 카드를 확인할 수 있어야 한다. 좌표·최종 아트·해상도별 배치는 미결정이다.

UI-04 선택 미확정은 빨간색 NOT READY, 확정 완료는 초록색 READY로 표시한다. 선택만 했고 확정하지 않았다면 NOT READY다. 시간 초과에 의한 확정도 READY다. 다음 선택 단계에 진입하면 두 플레이어 모두 NOT READY로 초기화한다.

UI-05 현재 족보를 한 줄로 보여주고 실제 구성 카드를 강조한다. 자세히 보기를 누르면 사용한 5장과 숫자·키커 비교를 확인할 수 있게 한다. 현재 프로토타입에는 구성 카드 텍스트와 강조가 있으며 별도 상세 패널은 아직 없다.

UI-06 교체 대상으로 선택하기만 한 카드는 아직 보유 카드다. 현재 족보는 실제 교체 완료 또는 새 공용 카드 공개 후 갱신한다. 선택만으로 계산에서 제거하지 않는다.

UI-07 조커 후보마다 현재 카드 기준 점수를 표시한다. 현재 성립한 조건은 반영하고 마지막 카드가 필요한 조건은 미확정으로 안내한다. 숫자 보정·조건·최선 패는 마지막 카드 후 다시 평가한다. 현재 기준 점수는 예상 최종 점수나 승리 보장이 아니다.

UI-08 예측형은 숫자와 무늬를 지정할 수 있고, 입력하지 않아도 확정할 수 있다. 현재 프로토타입은 이미 알려진 정확한 카드를 예측 대상으로 지정하지 못하게 한다. 세부 선택 UI는 구현 선택이며 추가 사용성 검증 대상이다.

### 6 3 결과 연출

UI-09 약 5초 동안 양쪽에 같은 단계 순서를 적용한다. 활성 조커 동시 공개 → 마지막 공용 카드 → 개인 카드 동시 공개 및 최종 5장 강조 → 족보 기본 점수와 숫자 보정 → 조커 기본 효과 → 추가 효과 → 최종 점수와 승패 순서다.

UI-10 예측형은 점수 계산 단계에서 예측 카드와 실제 마지막 카드를 함께 보여준다. 숫자 적중과 완전 적중의 추가 보너스는 차례대로 보여준다. 배율형의 추가 효과는 적용 배율이 올라가는 연출이며 실제로 배율을 두 번 곱하지 않는다.

현재 코드의 세부 연출 구간은 0초 조커, 0.5초 마지막 카드, 1초 개인 패, 1.5초 기본 점수, 2.5초 기본 조커 효과·예측 공개, 3.5초 추가 효과, 완전 적중 시 4.2초 큰 보너스, 5초 승패다. 이 세부 초 단위 배분은 구현 선택이며 기획상 고정한 것은 전체 약 5초와 공개 순서다.

UI-11 매치 선택과 랭킹 목록에는 드래그 탐색·스크롤을 사용한다는 방향이 있다. 해당 화면은 아직 구현하지 않았다. 결과 연출 건너뛰기와 재대결 규칙도 미결정이다.

## 7 기권과 연결 종료

M-14 자발적 기권자는 보상을 받지 않는다. 대전 중 연결이 끊겨 판에서 이탈한 경우 기권 처리한다. 남아 있는 플레이어는 즉시 승리하며 정상 승리 보상을 받는다.

네트워크 끊김을 확정하는 기준, 재접속 유예 여부와 시간, 양쪽 동시 이탈, 서버 장애·매치 무효·중복 보상 방지는 네트워크·경제 구현 전 결정해야 한다. 모든 짧은 연결 흔들림을 즉시 기권으로 판정하는 구체적 기술 규칙은 아직 없다.

## 8 검수 조건

| ID | 확인 상황 | 기대 결과 |
|---|---|---|
| MT-01 | 한 장만 선택하고 교체 시간 종료 | 선택한 카드만 교체 |
| MT-02 | AI가 먼저 확정한 상태에서 본인 교체 시간 종료 | 교체 단계만 종료, 다음 단계의 AI 선택은 자동 잠기지 않음 |
| MT-03 | 한 명이 교체를 먼저 확정 | 버린 카드와 장수는 상대 확정까지 숨김 |
| MT-04 | 양쪽 교체 완료 | 공개한 버린 카드는 이후 재등장하지 않음 |
| MT-05 | 조커를 선택했지만 미확정 | 시간 초과 시 해당 조커 유지 |
| MT-06 | 조커 미선택, 후보 현재 점수 동률 | 후보 목록의 앞 조커 선택 |
| MT-07 | 예측형 선택 후 양쪽 조커 확정 | 조커 종류만 공개하고 예측 내용은 점수 계산까지 숨김 |
| MT-08 | 최종 점수 동률 | 숫자나 무늬로 재판정하지 않고 무승부 |
| MT-09 | 기권 또는 대전 이탈 확정 | 기권자 보상 없음, 남은 플레이어 승리 |

MT-09의 재화·네트워크 부분은 후속 구현 검수 항목이다. 현재 코드의 자동 검사는 기권 승패와 한 판 상태 전이까지 다룬다.
